# АссениGo — прототип

Учебный веб-сервис вызова ассенизаторских машин: клиент указывает адрес и объём,
система сама назначает свободную машину, водитель принимает или отказывается,
заказ проходит по статусам. Оплата наличными, всё внешнее (GPS, датчик бака,
СМС, Telegram, погода) — заглушки.

Готовы этапы 1–2: каркас, вход по телефону, главная с картой, форма заказа,
автовыбор машины, кабинет водителя и эмулятор датчиков. Цена, трекинг,
оценка и админка — в следующих этапах.

**Демо:** https://humus-team228.github.io/AsseniGo/ (после включения GitHub Pages)

## Как запустить локально

Сайт использует ES-модули и загружает seed-данные через `fetch`, поэтому
открывать `index.html` двойным кликом нельзя. Нужен локальный сервер.

```bash
# вариант 1 — Node.js
npx serve .

# вариант 2 — Python
python -m http.server 8000
```

Откройте адрес из вывода команды (например, `http://localhost:3000`
или `http://localhost:8000`). Для проверки с телефона используйте
адрес компьютера в локальной сети.

## Тестовые номера

| Роль | Номер |
|---|---|
| Клиент | +7 900 000-00-01 |
| Водитель | +7 900 000-00-11 |
| Админ | +7 900 000-00-99 |

Пароля и СМС нет: роль определяется по номеру из seed-данных.
На экране входа тестовые номера можно нажать.

## Что уже работает

- хэш-роутинг `#/`, `#/order`, `#/driver` (работает на GitHub Pages);
- вход по телефону и выход; текущий пользователь хранится в `sessionStorage`,
  чтобы в двух вкладках могли работать разные роли, данные — в `localStorage`;
- главная: герой, каталог из 5 услуг с ценами «от», карта машин, карточка
  последнего заказа (обновляется из другой вкладки);
- карта Leaflet + OpenStreetMap без ключа: маркеры со статусом, подсказка
  «рейтинг и бак», машина с баком 100 % скрыта; план Б — статичная схема
  и адрес текстом, если плитки не загрузились;
- форма заказа: адрес, объём 2/4/6/8/10 м³, точка на карте, валидация,
  превью; черновик переживает перезагрузку;
- «Оформить» → `pickDriver` сам выбирает машину и ставит статус `assigned`;
  клиент видит блок «Машину назначила система» с расстоянием, баком
  и рейтингом. Выбора машины и кнопки отмены нет, отмена и споры — только
  по телефону поддержки 8 800 000-00-00;
- если свободных машин нет — заказ остаётся в статусе `new`
  с пометкой «Свободных машин нет, оператор свяжется с вами»;
- кабинет водителя: рейтинг, отказы, статус, шкала бака, координаты,
  лента назначенных заказов, кнопки «Принять» / «Отказаться»,
  далее «В пути» → «На объекте» → «Завершить»; полей ввода бака и GPS нет;
- отказ снижает рейтинг на 0.3 и переназначает заказ другой машине;
  ниже порога 3.5 из `tariffs.json` водитель блокируется и видит экран
  «Аккаунт заблокирован. Обратитесь в поддержку»;
- эмулятор `sim.js`: раз в 2 секунды двигает свободные машины по кругам,
  ведёт машину к клиенту, прибавляет 25 % бака за заказ, при 100 % отправляет
  машину «на слив» и через 20 секунд опускает бак до 10 %;
- синхронизация вкладок через событие `storage`: заказ появляется у водителя,
  смена статуса сразу видна клиенту, без перезагрузки.

## Как проверить сценарий

1. Запустите сервер и откройте сайт. Вкладка 1 — клиент `+7 900 000-00-01`:
   `#/order`, адрес, объём, точка на карте, «Оформить».
2. Появится блок «Машину назначила система» с машиной, расстоянием, баком
   и рейтингом. Кнопки отмены нет — только телефон поддержки.
3. Откройте **новую** вкладку (не «дублировать») и войдите под номером
   водителя из блока (или `+7 900 000-00-11`). Заказ появится в ленте
   без перезагрузки.
4. Проведите заказ по кнопкам «Принять» → «В пути» → «На объекте» →
   «Завершить». На главной у клиента статус меняется сам.
5. Создайте второй заказ и нажмите «Отказаться»: рейтинг −0.3, в истории
   `new → assigned → rejected → assigned`, заказ уходит другой машине.

## Демо-панель `?dev=1`

Откройте сайт с параметром `?dev=1`, например
`http://localhost:8000/?dev=1`. Появится скрытая панель:

- переключатель погоды (сохраняется в `tariffs.weather`, влияет на цену
  в следующем этапе);
- «Заполнить бак» — выбранной машине ставится 100 %, она исчезает с карты
  клиента и из автовыбора, пока эмулятор не сольёт бак;
- «Ускорить симуляцию» — тики и слив ускоряются в 4 раза.

## Демо-данные

- 5 услуг, 8 машин (6 свободных, 1 занята, 1 с баком 100 %), 6 клиентов;
- 32 завершённых заказа, 18 адресов;
- данные лежат в `data/*.json` и при первом запуске копируются в `localStorage`.

Цены, тарифы и координаты в seed-данных — демонстрационные. Значения
тарифов взяты из допущений `PLAN.md` §8 и будут заменены после
подтверждения у РП и аналитика. Центр карты и симуляции — Воронеж.

Чтобы вернуть исходные данные, откройте консоль браузера и выполните:

```js
localStorage.clear();
location.reload();
```

## Структура проекта

```
index.html
css/style.css
js/app.js · router.js · store.js · api.js · map.js · sim.js
js/logic/dispatch.js · rating.js
js/pages/home.js · order.js · driver.js
data/services.json · drivers.json · clients.json · orders.json · tariffs.json
```

`map.js` — единственная точка входа `createMap()`, провайдер карты можно
заменить в одном файле. `logic/*` — чистые функции без DOM и `localStorage`,
их можно заменить, не трогая экраны.

## Публикация на GitHub Pages

Все пути относительные, сборки нет, `index.html` лежит в корне.

1. Закоммитить и запушить проект в ветку `main`:
   `https://github.com/Humus-team228/AsseniGo`.
2. В репозитории: **Settings → Pages → Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт откроется по адресу
   **https://humus-team228.github.io/AsseniGo/**.

После обновления файлов GitHub Pages кэширует их примерно на 10 минут —
делайте жёсткое обновление (`Ctrl+F5`). Leaflet подключается по CDN
и ключа не требует, поэтому переменные окружения и секреты не нужны.
